Besoin d'aide avec Composia ? Choisissez le canal adapté à votre question :

- [Ouvrez une issue Forgejo](https://forgejo.alexma.top/alexma233/composia/issues) pour les bugs, les demandes de fonctionnalités et les discussions publiques.
- Rejoignez le [groupe Telegram](https://t.me/composia) pour discuter avec la communauté.
- Envoyez toute question, y compris les failles de sécurité, à [support@composia.xyz](mailto:support@composia.xyz).

Si vous signalez une faille de sécurité, privilégiez l'e-mail tant que les détails ne doivent pas encore être publics.
